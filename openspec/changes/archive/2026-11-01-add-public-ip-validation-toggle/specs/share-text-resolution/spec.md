## MODIFIED Requirements

### Requirement: 无 Cookie 地逐跳展开短链

系统 MUST 手动处理有限次数的 HTTP(S) 重定向，正确解析相对 `Location`，并在每一跳验证允许的平台/媒体目标；公网 IP 校验默认开启，仅可通过部署方的运行配置临时关闭。全部跳转 SHALL 不发送 Cookie、不复用 `Set-Cookie`、不构造账号或游客身份；无法匿名展开时 MUST 明确失败。

#### Scenario: 相对地址与多跳短链
- **WHEN** 短链经过绝对或相对 `Location` 跳转到完整作品链接
- **THEN** 系统逐跳取得最终作品链接，且任一请求都不包含 Cookie

#### Scenario: 上游在跳转中设置 Cookie
- **WHEN** 首跳响应包含 `Set-Cookie` 并返回下一跳
- **THEN** 下一跳仍不发送 Cookie，且不建立会话或身份作为重试条件

#### Scenario: 越界或无法完成的跳转
- **WHEN** 跳转目标包含 URL 凭据、未允许域名，或在公网 IP 校验开启时指向非公开地址，或出现循环、超限、无有效目标
- **THEN** 系统终止解析并返回明确错误，不访问被拒绝的目标

#### Scenario: 关闭公网 IP 校验后仍限制跳转
- **WHEN** 部署方关闭公网 IP 校验，短链返回未允许域名、非默认端口、非法协议或含 URL 凭据的 Location
- **THEN** 在连接目标前拒绝跳转，仍不发送 Cookie 或本服务凭证

### Requirement: 依据完整特殊用途地址快照分类公网目标

系统 MUST 默认启用公网 IP 校验；仅部署方可通过运行配置临时关闭 IP 公网属性检查。校验开启时，系统 MUST 使用有来源和获取日期的 IANA IPv4、IPv6 特殊用途地址注册表快照进行本地分类，优先匹配最具体的前缀。特殊用途条目仅在目的地址有效、可转发且明确可全球到达时允许；False、N/A、空值及废弃条目 MUST 拒绝。系统 SHALL 拒绝多播、带接口区域编号的地址及尚未识别为全球单播的 IPv6 空间；该判断不代表实际网络可达性。无论开关状态，空 DNS 结果 MUST 拒绝，成功路径 MUST 固定解析或受控映射后的具体 IP 建连，不再次解析域名；关闭不豁免域名、协议、端口、URL 凭据或无 Cookie 限制。

#### Scenario: 父网段拒绝但特定子网允许
- **WHEN** 公网 IP 校验开启，地址同时命中拒绝的父网段和 IANA 明确允许的更具体条目
- **THEN** 使用最长前缀结果，例如允许 192.0.0.9/32 和 2001:1::1/128，不依赖规则排列顺序

#### Scenario: IPv6 特殊用途或废弃转换机制
- **WHEN** 公网 IP 校验开启，地址属于基准测试、文档、私有、链路本地、废弃或未明确全球可达的特殊用途网段
- **THEN** 拒绝连接，包括 2001:2::/48、3fff::/20、Teredo 和 6to4 等当前快照中的相应条目

#### Scenario: IPv4 嵌入 IPv6
- **WHEN** 公网 IP 校验开启，地址是 IPv4-mapped IPv6，或使用标准 NAT64 前缀 64:ff9b::/96
- **THEN** 内嵌 IPv4 必须通过同一 IPv4 规则，不能借外层 IPv6 形式访问本机、内网、云元数据或其他受限地址

#### Scenario: DNS 混合返回公网与受限地址
- **WHEN** 公网 IP 校验开启，同一目标的 DNS 结果中任意一个 IPv4 或 IPv6 地址未通过分类
- **THEN** 拒绝整个目标，并且成功路径只连接已验证的 IP，不在连接时再次解析域名

#### Scenario: 关闭分类后连接受控地址
- **WHEN** 公网 IP 校验明确关闭，允许域名的 DNS 或受控映射包含受限 IPv4、IPv6 或混合结果
- **THEN** 不因公网分类拒绝这些地址，仍固定结果建连并保留其他目标校验

#### Scenario: 关闭分类但没有可连接地址
- **WHEN** 公网 IP 校验关闭但 DNS 或受控映射为空
- **THEN** 拒绝目标，不尝试未经解析的地址或回退其他域名
