## 1. 严格匿名可行性验证

当前完成 28/28 项任务。四类真实样本已通过匿名详情、正式 Minimal API、顺序/配对比对、独立客户端下载和系统解码；抖音启用且四项能力为 `supported`。最终 Linux 容器同样完成四类真实解析，670 项离线与 API 回归测试通过。证据见 [严格匿名验证记录](../../../docs/validation/cookie-free-douyin.md)。

- [x] 1.1 建立最小 .NET 验证入口与受控上游替身，证明 Cookie 处理和自动重定向关闭，所有显式请求头均不含 Cookie。
- [x] 1.2 验证首跳 `Set-Cookie`、相对跳转、多跳跳转及跨调用情况下均不携带 Cookie，不构造账号/游客身份或启动浏览器。
- [x] 1.3 准备公开视频、普通图集、实况图集、混合图集四类真实公开样本，建立脱敏的验证矩阵与结果记录格式；真实输入仅存仓库外，链接、作品 ID 和原始响应不入库。
- [x] 1.4 分别验证公开分享页/元数据候选入口的无 Cookie 响应，记录能取得的字段、拒绝或结构变化，不预设匿名详情接口可用。
- [x] 1.5 对可取得媒体的样本解析最终 CDN 地址，由独立客户端使用返回 URL 和头部下载，核对图集数量、顺序和每项实况的完整配对。
- [x] 1.6 汇总逐类型通过/失败证据及本地签名调查结果；无可用匿名入口时保持平台关闭，可继续独立验证 API 和协议组件，四类全部通过前不得宣称本变更功能验收完成。
